---
name: User language preference
description: کاربر خواسته همیشه به فارسی پاسخ داده شود
---

**قانون:** همیشه به فارسی پاسخ بده، حتی اگر سوال به زبان دیگری باشد.

**Why:** کاربر در مکالمه صریحاً گفت «پاسخ‌ها را همیشه به فارسی بگو».

**How to apply:** در تمام پاسخ‌های چت فارسی استفاده کن. کدها، نام فایل‌ها و اصطلاحات فنی می‌توانند انگلیسی بمانند.
